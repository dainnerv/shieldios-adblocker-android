# Shield iOS — Bloqueador de Anuncios Local para Android

Aplicación Android nativa (Kotlin + Jetpack Compose) con interfaz estilo iOS que crea una **VPN local solo de DNS** (`10.0.0.1`) para bloquear anuncios y rastreadores sin ralentizar el internet ni enviar tráfico fuera del teléfono.

## Cómo generar tu APK en 3 minutos (sin Android Studio)

1. Crea un repositorio nuevo en [GitHub](https://github.com/new) (puede ser privado).
2. Descomprime este archivo `.zip` y sube todo su contenido (asegúrate de incluir la carpeta oculta `.github/workflows/build.yml`).
3. Ve a la pestaña **Actions** en tu repositorio de GitHub.
4. Verás el flujo **Compilar APK Shield iOS** ejecutándose automáticamente.
5. Al terminar (~2-3 minutos), entra en la ejecución y descarga **ShieldIOS-AdBlocker-APK** desde la sección **Artifacts**.
6. Descomprime el archivo descargado e instala `app-debug.apk` en tu Android.
